# 🛰️ Smart City QR Pole — Satellite Command Dashboard

> A satellite-connected Smart City QR Pole dashboard integrating ISRO NavIC & GPS for real-time bus tracking, train status, hospital availability, emergency services, weather forecasting, and civic complaint management across India.

## ✨ Features

| Feature | Description |
|---|---|
| 🗺️ India Map | Interactive live map with bus, train & flight routes |
| 🚌 Bus Tracking | Real-time bus tracking via ISRO NavIC + GPS |
| 🚂 Train Status | Live train arrival & delay information |
| 🏥 Hospitals | Nearby hospital bed availability & wait times |
| 🚨 Emergency | India emergency helplines & nearest services |
| 🛰️ Satellite | ISRO NavIC satellite connection status & orbit view |
| 🌤️ Weather | 5-day satellite weather forecast |
| 🏛️ Tourism | Nearby tourist attractions in Chittoor |
| 📶 Wi-Fi | Free Wi-Fi zones with satellite backhaul |
| 📢 Alerts | Live government alerts & announcements |
| 📝 Complaint | Civic complaint submission via satellite |

## 🚀 Getting Started

### ▶️ Run Locally

```bash
# Clone the repository
git clone https://github.com/tech-bharathi/smart-city-qr-pole.git

# Navigate to project folder
cd smart-city-qr-pole

# Open in browser
open index.html
```

### 🌐 Deploy on GitHub Pages

1. Go to **Settings → Pages**
2. Select **Branch:** `main`
3. Click **Save**
4. Your site will be live at:

```
https://tech-bharathi.github.io/smart-city-qr-pole
```
